# Slider sweep: 200mm -> 1000mm (20cm -> 100cm), 100mm steps.
#
# - Only the slider moves; pan/tilt keep their pre-adjusted values (movslide).
# - reconstruct.py owns the USB sensor, so do NOT connect the sensor in MkECTL
#   (Initialize the motors only). Connecting it would make the device busy.
# - Before running, replace <CALIB_DIR> with the directory holding
#   trajectory_data.bin (reconstruct.py --calib-dir).
# - If pyusb / iltrecon live in a separate venv, replace "python3" with that
#   interpreter path. reconstruct.py is referenced by absolute path so its
#   sibling "iltrecon" package is importable regardless of cwd.
# - Each location writes data/sweep/dist_XXXX/frame0000..frame0099.ply (+ depth npy).
#   Use --frame all so every frame is kept; precision = std over those frames,
#   accuracy = mean vs. the commanded distance.
#
# Mounting offset between the slider z command and the true sensor-to-wall
# distance (calibrated: offset = commanded - measured). With this set, the
# movslide arguments below are TRUE sensor-to-wall distances, so the dist_XXXX
# folder names are correct ground-truth labels for the accuracy computation.
